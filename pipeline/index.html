Architecture & Methodology

2.5D Adaptive LiDAR Processing Pipeline

A sensor-centric, distance-adaptive perception pipeline that transforms dense 3D LiDAR point clouds into a compact, semantically rich 2.5D representation while preserving detail where it matters.

Core Algorithms Spotlight
Algorithm 1

RandLA-Net

Point-Wise Semantic Segmentation

A point-cloud segmentation network used to classify the environment at point level. Its semantic output provides the foundation for separating terrain, static structures, and dynamic objects before rasterization.

Drivable Terrain Non-Drivable Static Obstacles Dynamic Objects
Algorithm 2

DBSCAN

Density-Based Spatial Clustering

A density-based clustering method applied to segmented spatial regions to separate individual object instances. It does not require a predefined number of clusters and can identify irregularly shaped groups while rejecting sparse noise.

Spatial Clustering Arbitrary Shapes Noise Rejection Object Instances
Pipeline Stages (At-a-Glance)
Stage 01

Point-Cloud Preprocessing

Prepares the incoming LiDAR point cloud for downstream perception by reducing unnecessary point-level redundancy while preserving essential scene geometry.

Key Operations
  • Spatial alignment & normalization
  • Noise & outlier removal
  • Point-cloud preparation
Stage 02 · RandLA-Net

Semantic Segmentation

Classifies the 3D environment point-by-point to establish semantic boundaries for downstream layer separation.

Semantic Classification
  • Drivable vs. non-drivable terrain
  • Static structures & barriers
  • Dynamic objects
Stage 03 · DBSCAN

Object Detection

Groups segmented points into spatial clusters to identify individual obstacle instances without requiring a predefined number of objects.

Instance Properties
  • Object spatial extent
  • Height boundaries
  • Semantic class association
Stage 04

Sensor-Centric Radial Grid

Divides the environment into concentric radial bands whose spatial resolution changes according to distance from the sensor.

Distance Resolution
Near High Detail
Mid Medium Res
Far Coarser
Stage 05

Adaptive 2.5D Rasterization

Maps segmented and clustered scene information onto the radial grid, condensing point-level geometry into multi-layer summaries for each occupied cell.

Multi-Layer Summaries
Ground Elevation + variation
Static Obstacle min/max Z
Dynamic Object min/max Z
Stage 06

2.5D Data Structure

Organizes the rasterized environment as a sparse radial structure. Empty cells are omitted rather than represented explicitly.

Sparse Representation
  • Occupied cell IDs
  • Layer-presence information
  • Semantic metadata

Distance-Adaptive Representation

LiDimention concentrates spatial detail near the sensor and progressively reduces representation density with distance, transforming dense 3D point clouds into a sparse 2.5D structure suitable for compact encoding and streaming.
