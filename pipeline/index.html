Architecture & Methodology

2.5D Adaptive LiDAR Processing Pipeline

A sensor-centric, distance-adaptive perception pipeline that transforms dense 3D LiDAR point clouds into a compact, semantically rich 2.5D representation—preserving detail where it matters.

End-to-End Pipeline Flow
01. Preprocessing → 02. RandLA-Net (Segmentation) → 03. DBSCAN (Clustering) → 04. Adaptive Radial Grid → 05. 2.5D Rasterization → 06. Sparse Data Structure → 07. 10B Encoding → 08. Compression → 09. Visualization
Core Algorithms Spotlight
Algorithm 1

RandLA-Net

Point-Wise Semantic Segmentation

High-efficiency deep neural network used to classify dense 3D point clouds at scale. It segments the environment into functional layers without heavy point-sampling bottlenecks, providing the foundation for multi-layer 2.5D decomposition.

Drivable Terrain Non-Drivable Static Obstacles Dynamic Objects
Algorithm 2

DBSCAN

Density-Based Spatial Clustering

Non-parametric spatial clustering applied across segmented obstacle layers. It detects distinct object instances of arbitrary geometry and rejects noise without requiring a predefined cluster count (k), enabling precise object extraction.

Spatial Clustering Arbitrary Shapes Noise Outlier Rejection Object Instances
Pipeline Stages (At-a-Glance)
Stage 01

Point-Cloud Preprocessing

Prepares raw LiDAR points for downstream perception, reducing point redundancy while preserving essential scene geometry.

Key Operations
  • Spatial alignment & normalization
  • Noise & outlier elimination
  • Initial ground extraction
Stage 02 • RandLA-Net

Semantic Segmentation

Classifies the 3D environment point-by-point to establish semantic boundaries for downstream layer separation.

Semantic Classification
  • Drivable vs. non-drivable terrain
  • Static structures & barriers
  • Dynamic vehicles & pedestrians
Stage 03 • DBSCAN

Object Detection

Groups segmented points into spatial clusters to identify individual obstacle instances without predefined object counts.

Instance Properties
  • Object centroid & 3D spatial extent
  • Min/max height boundaries
  • Semantic class association
Stage 04

Sensor-Centric Radial Grid

Divides space into concentric radial bands that progressively scale spatial resolution based on distance from the sensor.

Distance Resolution Bands
Near High Detail
Mid Medium Res
Far Efficient
Stage 05

Adaptive 2.5D Rasterization

Maps segmented points onto the radial grid, condensing millions of points into multi-layer height summaries per occupied cell.

Multi-Layer Summaries
Ground Elevation + variation
Static Obstacle min/max Z
Dynamic Object min/max Z
Stage 06

2.5D Data Structure

Organizes the environment as a sparse radial structure. Empty cells are completely omitted, preserving bandwidth and memory.

Sparse Representation
  • Separated Cell IDs & Payloads
  • Layer-presence bitflags
  • Semantic category metadata
Stage 07

Compact Binary Encoding

Packs multi-layer cell information into a fixed, ultra-compact payload, shrinking raw LiDAR data by orders of magnitude.

Cell Payload Specification
  • 10 bytes per occupied cell
  • Packed ground elevation & variance
  • Static & dynamic height boundaries
Stage 08

Compression & Streaming

Applies high-ratio entropy coding over sparse frames for ultra-low latency incremental network transmission.

Streaming Properties
  • Zstandard compression (3.5–5×)
  • Output: ~1–3 MB/sec bandwidth
  • Real-time frame transfer (25 FPS)
Stage 09

Visualization

Decodes the compact stream in-browser and renders the radial 2.5D environment seamlessly with WebGL / Three.js.

View Capabilities
  • 3D displaced terrain & obstacles
  • 2D semantic top-down mapping
  • Interactive distance-adaptive discs
